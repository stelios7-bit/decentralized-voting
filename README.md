# Decentralized Voting

A simple decentralized voting system: a Solidity `Voting` smart contract on
Ethereum, integrated with a Node.js backend over web3.js.

## Features (planned)

- Owner-only candidate registration
- One vote per address
- Retrieve all candidates with their vote counts
- Declare the winner
- REST API — candidates (POST / GET), vote (POST), winner (GET)

## Stack

- Solidity + Hardhat
- web3.js
- Node.js / Express
- chai / mocha for contract tests

## Status

In active development, PR-driven. See the issues and milestones for scope.
