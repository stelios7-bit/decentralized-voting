# Decentralized Voting

A simple decentralized voting system: a Solidity `Voting` smart contract on
Ethereum, integrated with a Node.js backend over web3.js.

The owner registers candidates, every address may vote once, and anyone can
read the standings or the current winner — both on-chain and through a REST API.

## Architecture

```
contracts/Voting.sol      on-chain logic (candidates, voting, winner)
      │  deploy (hardhat-deploy)
      ▼
shared/Voting.json        { address, abi }  ← generated on deploy
      │  loaded by
      ▼
backend/ (Express+web3.js) REST API over the contract
```

## Stack

- Solidity `0.8.24` + Hardhat
- `hardhat-deploy` for deployment
- web3.js + Node.js / Express
- chai / mocha for contract tests

## Prerequisites

- Node.js 18+

## Setup

```bash
npm install
```

## Run (local)

Use three terminals:

```bash
# 1 — start a local Ethereum node
npm run node

# 2 — deploy the contract (writes shared/Voting.json)
npm run deploy:localhost

# 3 — start the backend API
npm run backend
```

Copy `.env.example` to `.env` to override defaults (RPC URL, port).

## Test

```bash
npm test          # contract unit tests (chai/mocha)
```

## API

Base URL: `http://localhost:3000`

| Method | Path          | Body                          | Description                         |
| ------ | ------------- | ----------------------------- | ----------------------------------- |
| GET    | `/health`     | —                             | Chain connectivity + bound contract |
| GET    | `/candidates` | —                             | List candidates with vote counts    |
| POST   | `/candidates` | `{ name }`                    | Add a candidate (owner account)     |
| POST   | `/vote`       | `{ address, candidateIndex }` | Cast one vote from `address`        |
| GET    | `/winner`     | —                             | Name of the leading candidate       |

### Examples

```bash
# add a candidate (owner)
curl -X POST localhost:3000/candidates \
  -H 'Content-Type: application/json' -d '{"name":"Alice"}'
# -> { "name": "Alice", "txHash": "0x..." }

# list
curl localhost:3000/candidates
# -> [ { "index": 0, "name": "Alice", "voteCount": 0 } ]

# vote
curl -X POST localhost:3000/vote \
  -H 'Content-Type: application/json' \
  -d '{"address":"0x7099...","candidateIndex":0}'
# -> { "voter": "0x7099...", "candidateIndex": 0, "txHash": "0x..." }

# winner
curl localhost:3000/winner
# -> { "winner": "Alice" }
```

Contract reverts are returned as `400` with the custom-error name, e.g.
`{"error":"AlreadyVoted()"}`.
